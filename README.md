# 💜 Nexora Finance

### Sua vida financeira em um só lugar.

O **Nexora Finance** é um projeto de dashboard financeiro desenvolvido para proporcionar uma experiência moderna, intuitiva e organizada no gerenciamento de finanças pessoais.
Com uma interface elegante em tons de roxo e modo escuro, a plataforma permite visualizar informações financeiras, acompanhar receitas e despesas, organizar metas e monitorar movimentações.

## 🌐 Demonstração

🔗 **Acesse o projeto online:** https://shwnzzzz.github.io/NexoraFinance-ProjectShw/

## ✨ Funcionalidades

- 📊 Dashboard com visão geral financeira.
- 💰 Carteira com saldo total.
- 📈 Gráfico de fluxo de caixa.
- 💸 Acompanhamento de receitas e despesas.
- 🎯 Metas financeiras com indicadores de progresso.
- 💳 Interface de cartão virtual.
- ⚡ Ações rápidas para movimentações.
- 📋 Histórico de atividades recentes.
- 🔍 Campo de busca de transações.
- 🌙 Interface Dark Mode.

## 🎨 Identidade Visual

O projeto utiliza uma identidade visual moderna, com foco em simplicidade, tecnologia e sofisticação.

- **Cor predominante:** Roxo.
- **Estilo:** Dark Mode.
- **Design:** Moderno e minimalista.
- **Experiência:** Interface intuitiva e organizada.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- React
- Bibliotecas externas via CDN

## 🎯 Objetivo do projeto

O Nexora Finance foi desenvolvido como projeto de portfólio, com o objetivo de colocar em prática conhecimentos de desenvolvimento web, programação JavaScript, construção de interfaces e princípios de UI/UX Design.
